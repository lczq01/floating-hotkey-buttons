# Floating Hotkey Buttons（悬浮快捷键按钮）

[English](README.md) | [简体中文](README.zh-CN.md)

Windows 桌面悬浮快捷键按钮工具：把常用按键（组合键、功能键、特殊键）做成一个个可自由拖动、缩放的悬浮小按钮，点击即发送对应按键。适合触屏、数位板、单手操作或想少按组合键的场景。

基于 Python + Tkinter 标准库实现，**零第三方依赖**，无需安装，解压即用。

## 功能特性

- **独立悬浮小窗**：每个按钮是独立的置顶窗口，鼠标悬停不夺焦，不影响当前输入焦点
- **半透明优雅**：闲置时半透明（0.6），悬停时清晰（0.95）
- **三手势交互**：
  - 主体拖动 = 移动位置（原地松开 = 点击发送按键）
  - 右下角隐形手柄拖动 = 缩放（40×24 ~ 200×120，字号自适应）
  - 右键 = 菜单（编辑 / 新增 / 删除 / 收入库 / 最小化 / 退出）
- **按键绑定双方式**：
  - 录制：点击「录制」后直接按键捕获（低层键盘钩子，不怕其他软件热键拦截）
  - 文字输入：直接输入 `Ctrl+Shift+S`、`回车`、`F5`、`←` 等，即时校验识别
- **按钮库**：右键「收入库」把按钮收进右下角库图标，需要时再取出，位置/大小/绑定全部保留
- **持久化**：所有按钮（含库内存件）自动保存到 `config.json`，重启恢复
- **最小化**：全部按钮收起为右下角一个小圆点，点击恢复

## 运行方式

环境要求：Windows 10/11 + Python 3.8+（仅标准库）

```bat
pythonw vkb.py
```

或直接双击 `启动悬浮键盘.bat`。

首次运行会出现一个居中的「按钮1」，右键它即可开始：编辑绑定、加载 10 个常用示例按钮（复制/粘贴/剪切/撤销/回车/退格/删除/F1/F5 等）。

## 配置文件

`config.json` 与脚本同目录，结构如下（程序自动维护，一般无需手改）：

```json
{
  "buttons": [
    {
      "text": "复制",          // 按钮显示文字（≤6 字）
      "mods": ["ctrl"],        // 修饰键：ctrl / alt / shift
      "key": "c",              // 主键（Tk 键名）
      "x": 1147, "y": 593,     // 屏幕坐标
      "w": 60, "h": 36,        // 按钮尺寸
      "stored": false          // true = 在按钮库中
    }
  ]
}
```

## 已知限制

- 不支持绑定 Win 键与 Esc 键
- 无法向管理员权限运行的窗口发送按键
- 录制期间会临时拦截全系统按键（Esc 结束录制）
